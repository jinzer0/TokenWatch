# 첫 화면 대시보드 지표 조사

상태: 탐색 결과. 아래 후보는 사용자 채택 전이며 시각 디자인이나 구현 승인으로 간주하지 않는다.

## 확정된 요구

- Electron 데스크톱 앱을 사용한다는 인상. 특정 OS 네이티브 디자인 모방은 목적이 아니다.
- 타이틀바와 본문이 단절되는 느낌 및 전체적인 웹 같은 시각 인상 개선.
- 첫 화면은 토큰 사용량 대시보드. 구독 플랜 사용 현황 및 일간·주간 간략 통계 확인.
- 지원 대상: Claude, ChatGPT Codex, Cursor.

## 조사 근거

### 기존 구현

- `src/desktop/renderer/src/components/DashboardContent.tsx`: 사용량·비용 차트, 모델·소스 분포, 세션 요약, 진단, 공유, 상세 집계가 같은 대시보드에 구성되어 있다.
- `src/desktop/shared/contracts.ts`: 로컬 토큰 집계, 세션 요약, 스캔 결과, 진단과 생성 시각을 제공한다. 구독 플랜별 잔여 한도 DTO는 확인되지 않았다.
- `src/desktop/shared/dashboardAnalyticsContracts.ts`: 이전 기간과 비교한 추세, 모델·소스·프로젝트별 집계, 캐시 비율 및 미확정 비용을 표현한다. 기존 rolling 기간과 달력 기준 오늘·이번 주를 혼용하지 않아야 한다.
- `src/desktop/renderer/src/hooks/useTokenWatchDashboard.ts`: 초기 조회 및 명시적 새로고침을 수행한다. 이 훅에는 자동 갱신 타이머나 실시간 이벤트 구독이 없다. 화면 재조회 시각이 수집 데이터의 최신 시각을 보장하지 않는다.
- `src/services/providerUsage.ts`: OpenAI·Anthropic API 키로 models 엔드포인트를 탐지한다. quota는 unknown이고 구독 플랜 한도 조회 구현이 아니다. API rate limit을 구독 한도와 혼동하면 안 된다.

### 공식 외부 문서

- [Claude 사용량·길이 제한](https://support.claude.com/en/articles/11647753-how-do-usage-and-length-limits-work): 사용량 제한과 컨텍스트 길이 제한은 다르며 Claude의 여러 제품 표면이 구독 사용량을 공유한다.
- [Codex 가격·사용량 안내](https://developers.openai.com/codex/pricing/): 조회 시 ChatGPT 공식 문서로 이동했다. 구독 사용량과 API 토큰 가격은 별개이며 한도·리셋은 사용량 대시보드에서 확인하도록 안내한다. 구체적인 플랜 가격·모델 이름·기간 값은 이번 설계에서 고정하지 않는다.
- [Cursor 모델·가격 안내](https://cursor.com/docs/models-and-pricing): 조회 문서는 서로 다른 사용량 풀과 청구 주기를 설명한다. 하나의 토큰 사용률로 모든 플랜을 동일하게 표현할 수 없다.

외부 문서 조회는 표시 의미를 조사한 것이며 TokenWatch에서 해당 데이터를 수집할 수 있다는 검증이 아니다. 개인 계정이나 자격증명에는 접근하지 않았다. 한 Claude 문서 URL은 404였으나 별도의 공식 사용량 문서를 확보했다.

## 제안하는 정보 우선순위

사용자 확인 전 후보이며 레이아웃·색상·카드 패턴을 확정하지 않는다.

1. 구독별 현재 상태: Claude / ChatGPT Codex / Cursor. 각 서비스가 제공하는 단위와 주기에 맞춰 표시.
2. 오늘·이번 주의 로컬 토큰 사용량과 비교 통계. 구독 사용률과 시각적·의미적으로 분리.
3. 짧은 추이와 서비스별 사용 비중.
4. 작고 상시 확인 가능한 데이터 최신성 및 주의 상태. 문제가 없으면 주의를 끌지 않음.
5. 상세 비용, 세션, 모델·프로젝트 집계, 스캔 로그, 진단 전문은 별도 분석·진단 영역 후보.

## 데이터와 개인정보 원칙

- Claude에서 사용한 모델을 Cursor로 호출했다고 Claude 구독 사용량에 더하지 않는다. 서비스와 모델 제공자를 구분한다.
- 서비스별 한도는 서로 다른 단위·주기일 수 있으므로 통합 잔여 퍼센트를 만들지 않는다.
- 확인되지 않은 플랜·한도·리셋·가격은 미확인으로 표현하며 0으로 대체하지 않는다.
- 실제 구독 사용률은 로컬 토큰 합계나 API rate limit으로 추정하지 않는다.
- 자동 갱신이 구현되지 않은 상태에서 실시간이라고 표시하지 않는다.
- 원본 기록, 프롬프트, 응답, 계정 자격증명, 원본 경로 및 원본 세션 식별자를 설계 문서·UI·IPC·DB에 추가하지 않는다.

## 미확정 사항

- 구독 데이터의 합법적·안전한 수집 경로 및 서비스별 가용성.
- 개인용인지 팀 공용인지와 주요 사용자.
- 자동 갱신 기대 주기 및 수집 지연 허용 범위.
- 오늘·이번 주의 시간대와 주 시작 요일.
- 첫 화면 후보의 채택 여부, 상세 화면 구분 및 시각적 방향.
- 첫 화면 확인 후 사용자가 이어서 수행할 행동.

## 조사 범위의 한계

기존 코드와 공식 문서만 읽었다. 앱 실행·계정 연결·구독 API 검증·제품 소스 변경은 하지 않았다. 이는 UX 후보를 위한 근거 조사이지 기능 구현 완료나 실시간 연동 가능성 보증이 아니다.
