# 데스크톱 UX/UI 리팩터링 — 잠정 보고

요청한 설계 정리를 **잠정 초안으로 작성 완료**했다. 최종 워크플로 종료·정식 최종 승인·기술 타당성 확정·제품 구현 승인을 뜻하지 않는다. 추가 확인 질문 없이 [최신 결정 기록](.memlog.md)을 반영했다.

## 확정 사항

- 대상은 Electron 데스크톱, 서비스는 Claude·ChatGPT Codex·Cursor다. 첫 화면은 남은 사용량 중심 대시보드다.
- 통합 타이틀바/도구 영역, 좌측 일간·주간 요약/증감/추이, 우측 서비스별 잔여량/리셋/사용 여유, 하단 비중/선택 상세 배치를 유지한다.
- Graphite·Paper·Slate를 모두 지원하며 Graphite가 최초 기본이다. 앱 설정에서 선택하고 재실행 후 마지막 선택을 유지한다.
- 구독 잔여량은 퍼센트 중심, 사용 여유·부족은 리셋까지 필요량 대비로 구분한다. 앱 화면의 가상 단위·공식·긴 면책 문장은 제외한다.
- 전망 방식은 SES, 최소 유효 이력 7일·최근 최대 30일 **계산 입력**이다. 보존 기간 변경이나 과거 데이터 삭제 요청이 아니다.

## 잠정 기본값

- 개인 개발자 맥락, 테마 즉시 적용·로컬 저장·OS 자동 연동 없음, 테마 변경 시 서비스/기간 유지.
- 시스템 시간대의 오늘·월요일 시작 이번 주, 어제/지난주의 같은 경과 구간 비교. 리셋은 서비스 제공 시각 우선.
- 보이는 창에서 60초 간격·수동 새로고침·창 복귀 시 한 번 갱신. 실제 실시간 연결이나 수집 허용을 보장하지 않는다.
- 작은 창에서 주 사용량 영역 우선 보존, 키보드·포커스 복원·스크린리더·동작 감소·대비 목표 적용.
- 화면 설정은 비용 절감 요청에 따라 **spine-only provisional**이다. 새로운 설정 시안은 만들지 않았다.

## 산출물과 판단

- [DESIGN.md](DESIGN.md): 실제 HTML 색상·타이포그래피·간격·컴포넌트 토큰, 테마별 매핑과 시각 계약.
- [EXPERIENCE.md](EXPERIENCE.md): IA, 계산 의미, 상태/실패 처리, 세 Key Flows, 설정 지속성·접근성 계약.
- 시각 근거: [Graphite](.working/direction-graphite.html) · [Paper](.working/direction-paper.html) · [Slate](.working/direction-slate.html) · [Excalidraw](.working/dashboard-layout.excalidraw). 기존 파일은 변경하지 않았다.
- 앞선 시안의 날짜·요일은 예시다. `최근 7일` 주간 요약과 충돌하면 최신 달력 기간 결정을 따른다.
- 승인된 `_bmad-output/initiative-desktop-ux-ui-refactor/ux-desktop-ux-ui-refactor/`는 이번 initiative의 작업 공간이다. 공식 공개 문서 루트 변경이나 `mydocs/`·`docs/` 정책 변경으로 해석하지 않는다.

## 구현 전 기술 전제

1. 서비스별 권위 있는 quota 수집 경로·접근 정책·단위·사용량 풀·한도·리셋 검증이 필요하다. 기존 provider 탐지는 구독 잔여량 연동 완료가 아니다.
2. SES의 α·초기화·bucket 단위·관측 완전성·실측 오차, 달력 비교 경계, 최신성 기준·60초 수집 가능성을 검증해야 한다. 누락을 0으로 채우거나 합성 데이터로 대체하지 않는다.
3. 테마 저장/재실행/실패 처리, OS titlebar hit region, 키보드·포커스·대비·축소 창의 실제 동작은 구현 검증 대상이다. 미확인 가격은 `null`로 유지한다.

## 검증 범위와 제외

- 기존 HTML은 1440×1000 시각 검토, 1000px 잘림 검사, 오프라인 HTML 및 Excalidraw 기본 구조 확인을 마쳤다. [기록](.memlog.md)에 해당 범위가 남아 있다.
- 새 문서 세 파일의 YAML·출처 및 상대 링크, 토큰 참조, 시안 원본 색상 일치, 두 계약의 컴포넌트 이름, 필수 섹션과 세 사용자 흐름의 핵심·실패 경로를 기계적으로 확인했다. 제품 테스트나 전면 UX 평가를 대체하는 검사는 아니다.
- 선택적 다중 에이전트 UX 검증은 실행하지 않았다. 실제 Excalidraw 앱 가져오기, 제품 동작·접근성·예측 정확도 검증 완료를 주장하지 않는다.
- 제품 코드 구현·앱 실행·네트워크/계정 접근·커밋·PR·새 시안 제작은 하지 않았다. 정식 최종화는 별도 선택 절차로 남으며 이번 요청의 추가 승인 질문으로 되돌리지 않는다.
