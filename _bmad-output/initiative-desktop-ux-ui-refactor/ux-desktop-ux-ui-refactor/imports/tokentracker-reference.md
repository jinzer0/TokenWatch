# 사용자 제공 참고: TokenTracker

출처: https://github.com/xiufengsun/TokenTracker

사용자가 데스크톱 앱 인상의 참고 대상으로 제공했고, 대시보드의 정보 배치를 선호한다고 확인했다. 이 문서는 외부 프로젝트의 규칙이나 기능을 TokenWatch에 채택하지 않는다.

## 확인한 자료

- 저장소 README의 기능 설명과 Showcase.
- 저장소 DESIGN.md의 시각 시스템 설명.
- README의 대시보드 이미지: 브라우저에서 열린 화면이며, 기간 선택·큰 토큰 합계·서비스별 비중·추이·상세 표가 있다.
- README의 메뉴바 패널 이미지: 작은 독립 패널 안에 요약 통계·활동·추이·모델 목록을 배치한다. 상단과 본문이 같은 표면으로 이어지고 하단에 대시보드 열기와 종료 동작이 있다. GIF 조회 도구가 제공한 정지 프레임을 확인했으며 애니메이션이나 실제 상호작용을 실행하지 않았다.

## 확정된 참고 범위

- 참고 대상은 대시보드의 정보 배치다. 메뉴바 패널의 스타일이나 메뉴바·트레이 기능 추가는 승인되지 않았다.
- TokenWatch 적용 배치: 상단의 통합된 앱 도구 영역, 왼쪽 일간·주간 요약과 증감·짧은 추이, 오른쪽 서비스별 잔여량·리셋·사용 여유, 그 아래 서비스 사용 비중과 선택한 서비스 상세.
- 큰 누적 토큰 수보다 지금 얼마나 더 사용할 수 있는지를 중심에 둔다.
- 색상, 투명도, 활동 히트맵, 캐릭터 등은 자동으로 채택하지 않는다.

외부 자료의 계정 표시나 원본 화면을 로컬 산출물에 복사하지 않고 참고 링크와 비식별 관찰만 기록했다. DESIGN.md·EXPERIENCE.md에서 확정된 TokenWatch 결정이 외부 참고보다 우선한다.
