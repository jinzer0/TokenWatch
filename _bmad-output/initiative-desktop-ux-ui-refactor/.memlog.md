updated: 2026-10-04T19:50

- (decision) 사용자가 지적한 문제: 현재 앱의 웹 같은 시각적 인상이 강하고 네이티브 데스크톱 앱처럼 느껴지지 않는다. 타이틀바와 메인 창이 자연스럽게 이어지지 않는다. 원하는 방향: 네이티브 데스크톱 디자인. 플랫폼별 기준과 구체적인 시각 언어는 아직 미확정.
- (decision) 네이티브 디자인의 의미를 사용자가 명확히 함: macOS 네이티브 디자인을 모방하는 것이 목적이 아니다. 웹브라우저 창이 아니라 독립된 데스크톱 앱 프로그램을 사용하고 있다는 인상을 주는 것이 목표다. 특정 OS 시각 언어 채택이나 지원 플랫폼 변경을 뜻하지 않는다. 타이틀바와 본문의 자연스러운 연결은 앞서 지적한 핵심 개선점으로 유지한다.
- (decision) 사용자가 현재 핵심 문제를 확정하고 이 방향으로 진행 승인: 창과 타이틀바의 단절감, 전체적인 웹 같은 시각 인상을 개선한다. 목표는 특정 OS 스타일 모방이 아닌 독립된 데스크톱 앱 경험이다. 구체적인 색상·레이아웃·컴포넌트 선택과 제품 소스 구현은 아직 승인되지 않았다.
- (decision) 설계 문서 위치 승인: initiative-desktop-ux-ui-refactor/ux-desktop-ux-ui-refactor 아래 DESIGN.md·EXPERIENCE.md를 작업 초안으로 작성한다. 제품 소스는 수정하지 않는다. 사용자 흐름: 앱을 열면 토큰 사용량 대시보드가 먼저 보인다. 현재 구독 중인 플랜의 실시간 사용량, 주간 사용량, 일간 사용량 등 간략 통계를 확인한다. 구독 플랜 데이터의 출처와 실시간 갱신 의미는 미확정이며 로컬 사용량과 구독 한도 사용률을 동일시하지 않는다.
